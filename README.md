📚 StudyAntra – AI Powered Learning Platform

🚀 StudyAntra is an AI-powered educational platform designed specifically for colleges and institutions to provide students with personalized learning based on their teacher’s syllabus, notes, and teaching style instead of generic AI responses.

The platform combines RAG (Retrieval Augmented Generation), local LLMs, and algorithm visualization to create an interactive and intelligent learning experience for students.

🌟 Key Features

✨ Teacher-Centric AI Learning

AI answers generated only from teacher-uploaded content
Institution-scoped learning system
Exam-priority topic flagging

✨ AI Chat Assistant

Natural language question-answering system
Context-aware responses using RAG pipeline
Local AI inference with Ollama

✨ Algorithm Visualization Engine

Step-by-step visualization for algorithms

Interactive play, pause, and navigation controls

✨ Assignment & Evaluation System

🧠 Architecture Overview
Teacher uploads syllabus, notes, and assignments
Content is converted into vector embeddings
Student submits a query
RAG engine retrieves relevant chunks
Ollama generates grounded AI responses
Visualization engine renders algorithms dynamically

The system ensures responses are generated only from teacher-approved content.

🎯 Problem Statement

Students often rely on generic AI tools that do not understand:

Their syllabus
Professor teaching style
Exam priorities
Institution-specific learning patterns

StudyAntra solves this by providing:
✅ Personalized AI learning
✅ Teacher-controlled content
✅ Institution-scoped responses
